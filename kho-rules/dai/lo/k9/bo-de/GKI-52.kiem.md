# GKI-52 — Pha 1 giải MÙ (trạm soát, Opus, 18/10)

Đề: THCS Ngô Gia Tự (phường Việt Hưng), 2025–2026, 1 trang scan, đọc lại phần Bài 1 ở 300 dpi. Không in đáp án.

| Nhãn | Đáp án / đáp số / hướng chứng minh | Ghi chú về đề |
|---|---|---|
| Bài 1.1a | $x=2$; $x=-3$ (phương trình tích) | |
| Bài 1.1b | ĐKXĐ $x\ne\pm3$; khử mẫu: $4(x-3)+(x-1)(x+3)=x^2+x$ ⇒ $5x=15$ ⇒ $x=3$ (loại) ⇒ vô nghiệm | |
| Bài 1.1c | $2x-6<5x$ ⇒ $-3x<6$ ⇒ $x>-2$ | |
| Bài 1.2 | $(x;y)=(7;5)$ (thế $x=32-5y$ ⇒ $13y=65$) | |
| Bài 2.1 | Gọi số ngày dự định $x$: $55(x-2)=50x+15$ ⇒ $x=25$ ⇒ $1250$ chiếc áo | lời văn |
| Bài 2.2 | $x+y=750$; $0{,}1x+0{,}2y=100$ ⇒ bàn là $500$ nghìn đồng, quạt $250$ nghìn đồng | lời văn |
| Bài 3 | $h=172\cdot\tan62^\circ\approx323{,}48$ ⇒ $\approx323{,}5$ m | hình là tháp Eiffel (ảnh chụp) |
| Bài 4a | $BC=10$ cm; $\tan B=\dfrac{8}{6}$ ⇒ $\widehat{B}\approx53^\circ$; $\widehat{C}\approx37^\circ$ | |
| Bài 4b | $\triangle AMB\backsim\triangle IMA$ (g.g: chung $\widehat{M}$, $\widehat{A}=\widehat{I}=90^\circ$) ⇒ $AM^2=IM\cdot BM$; $\sin\widehat{ABM}=\dfrac{AM}{BM}$ ⇒ $\sin^2=\dfrac{IM}{BM}$ | |
| Bài 4c | $\widehat{CAN}=\widehat{ABM}$ (cùng phụ $\widehat{AMB}$) ⇒ $\triangle ABM\backsim\triangle CAN$ ⇒ $\dfrac{MC}{CN}=\dfrac{AM}{CN}=\dfrac{AB}{AC}$ ⇒ $\triangle MCN\backsim\triangle BAC$ (c.g.c) ⇒ $\widehat{CMN}=\widehat{B}$ ⇒ $\widehat{CMN}+\widehat{MCK}=90^\circ$ ⇒ $MN\perp BC$ ⇒ $K\in MN$ (toạ độ kiểm: $MN\cdot BC=0$) | |
