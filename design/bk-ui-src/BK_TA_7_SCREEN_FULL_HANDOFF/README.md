# BK TA 7 Screen SVG Handoff

Gói này tổng hợp SVG + reference để dựng lại bộ 7 màn hình TA app.

## Màn hình đi kèm
1. Home
2. Điểm danh buổi học
3. Report & Báo tan
4. Chuẩn bị phòng
5. Test đầu vào
6. Quà của BK
7. Của tôi

## Cấu trúc
- `assets/common/`: icon dùng chung
- `assets/home/`: icon/illustration màn Home
- `assets/attendance/`: icon riêng màn Điểm danh
- `assets/report/`: icon riêng màn Report
- `assets/prep/`: icon riêng màn Chuẩn bị phòng
- `assets/test/`: icon riêng màn Test đầu vào
- `assets/gift/`: icon riêng màn Quà
- `assets/my/`: icon riêng màn Của tôi
- `references/screens/`: 7 ảnh reference full screen
- `spec/`: markdown + manifest

Dùng `spec/CLAUDE_REBUILD_GUIDE.md` làm tài liệu handoff chính cho Claude.
